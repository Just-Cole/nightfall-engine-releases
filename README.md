# Nightfall Engine — releases

Installers for the Nightfall Engine editor. The engine's source code is private; this repository
only holds published builds.

- **Download:** the newest installer is under [Releases](../../releases/latest).
- **Updates:** the editor checks this repository's latest release when it starts. If its tag is newer
  than the installed version, it offers to download and run the new installer.

Release tags are versions (`v0.1.0`, `v0.2.0`, ...). Each release carries one Windows installer.
